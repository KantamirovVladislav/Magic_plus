# Огненная стрела — рабочий стенд материала

Сцена: `Assets/FireBow/MaterialLab/Scenes/FireArrow_MaterialLab.unity`.
Префаб: `Assets/FireBow/MaterialLab/FireArrow_MaterialLab.prefab`.

Это редакторский прототип для Unity 6000.0.75f1 / URP 17.0.4.
Игровая DLL и материалы выпущенного снаряда не изменялись. Для переноса
в Valheim требуется отдельная проверка Built-in и сборка игровых ресурсов.

## Просмотр

Открой сцену, затем Game и Play. В Scene также включён Always Refresh.
На объекте `FireArrow - tuned material` находится центральная модель.
Дочерний объект `Optional flame tongues` можно выключить: это отдельные
добавочные языки, исходный FBX они не заменяют.

## Материалы

`Flame_Arrow_Core.mat` управляет центральным телом.
`Flame_Arrow_Tongues.mat` использует тот же граф, но разрешает разрушение кончиков.

| Поле | Назначение |
|---|---|
| Flow speed | Скорость течения рисунка |
| Pattern across / along | Масштаб рисунка поперёк и вдоль формы |
| Outer / Gold / Hot core color | Оранжевый край, золотой слой, светлое ядро |
| Hot core strength | Сила переменных светлых прожилок |
| Color intensity | Яркость цвета; чрезмерное значение скрывает градации |
| Sway amplitude (metres) | Амплитуда изгиба рабочей модели в метрах |
| Phase offset | Сдвиг рисунка по времени |
| Use authored UV | 0: координаты от формы; 1: авторская UV-развёртка |
| Tip erosion | Для центрального тела оставить 0; у отдельных языков используется 1 |

В графе `Flame_Arrow_Core.shadergraph` пять подписанных групп:

1. Время и чтение сохранённой UV0.
2. Два движущихся слоя шума.
3. Отдельное смешивание оранжевого, золотого и светлого цветов.
4. Изгиб по координатам меша, одинаковый на совпадающих вершинах UV-шва.
5. Отдельная маска исчезновения кончиков. При Tip erosion = 0 Alpha всегда равна 1.

В свойствах графа есть скрытые часы QA для воспроизводимой отрисовки кадров.
Обычные материалы используют штатное время Unity, Use manual time = 0.

## Геометрия и UV

`FireArrow_WorkingMesh.asset` — отдельная копия новой пользовательской модели
`fire_bow_Fixed_UV.fbx`. Её длина нормализована до 2 метров, центр находится
в начале локальных координат, длинная ось — Z от +1 к -1.
Авторская UV0 сохранена без изменений. Цвета вершин дополнены маской подвижности.
Фактический изгиб графа вычисляется по позиции, поэтому UV-шов не разрывает меш.

Включены координаты от формы: узкий и сужающийся UV-остров не стягивает
цветовой рисунок в одну полосу. Переключатель Use authored UV оставлен для сравнения.
Рабочая копия меша самостоятельна: следующий экспорт FBX из Blender не обновит
её автоматически; потребуется заново нормализовать геометрию рабочей копии.

Четыре дополнительных языка созданы как отдельный меш внутри Unity. Их
можно оставить как пробу, отключить или впоследствии заменить своими формами
из Blender. У одного графа разные настройки непрозрачности для ядра и языков.

## Исходники и восстановление

Пользовательские `Flame_Test.shadergraph`, `Flame_Test_Mat.mat` и оба FBX
не перезаписывались. Несохранённая тестовая сцена сохранена отдельной копией:

`Assets/FireBow/Backups/BeforeMaterialTuning_20261110_013733/test_snapshot.unity`.

Побайтовые копии исходных ассетов и manifest с SHA-256 лежат в проекте:
`Backups/FireBow/BeforeMaterialTuning_20261110_013733`.

Скрипты воспроизводимой подготовки находятся на Mac в
`tools/unity/FireBowMaterialLab`. Они используют установленный Unity CLI и
стандартный Python, новых сторонних зависимостей нет.
