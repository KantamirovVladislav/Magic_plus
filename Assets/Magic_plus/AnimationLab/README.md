# Лаборатория позы огненной стрелы

Сцена на HDPC: `Assets/Magic_plus/AnimationLab/Scenes/MagicPlus_TwoFingerPose.unity`.
Исходный стенд: `Scenes/MagicPlus_AnimationLab.unity`.
Меню **MagicPlus → Pose Lab** открывает окно управления. Работайте в **Scene**,
без Play. Сцена уже открыта после настройки.

1. На вкладке **Поза и руки** нажмите **Поза по референсам: два пальца**.
   Это отдельный стартовый вариант: левая рука вытянута, указательный и средний
   направлены вперёд, большой вниз; правая кисть у лица, хват двумя пальцами.
   **Поза лука из игры** возвращает оригинальную основу. Затем **Крупно: руки**.
2. Оставьте **Предпросмотр (IK)** включённым и выберите **Левая кисть**
   или **Правая кисть**. Клавиша **W** перемещает
   выбранную цель, **E** поворачивает кисть. **F** приближает выбранную точку.
3. Цели локтей задают сторону сгиба руки. Двигайте их, если локоть выворачивается.
4. **Прицел** управляет направлением позы. Двигайте вверх/вниз и в стороны.
5. Ползунок **Натяжение** перемещает тянущую кисть между подготовкой и удержанием.
6. На вкладке **Пальцы** выберите руку и палец. **Общий сгиб** управляет тремя
   суставами, **Разведение** — положением пальца в стороны. В **Отдельные суставы**
   можно менять каждый сгиб отдельно. **Поворот кисти** и кнопка выбора в Scene
   поворачивают кисть целиком. Ползунки работают с включённым IK и сразу
   сохраняют правки пальца в основу позы.
7. Для ручной правки нажмите **Редактировать сустав вручную**: выберется
   нужная кость и выключится IK. Поверните её клавишей **E**.
   Для торса также выключите **Предпросмотр (IK)** прямо в этом окне,
   вращайте нужные кости и нажмите **Запомнить правки верха тела**. После этого
   включение IK сохраняет новую основу. Таз и ноги этим действием не изменяются.
8. **Ctrl+S** сохраняет сцену. **Сохранить позу в JSON…** на вкладке **Поза и руки** сохраняет цели,
   основу торса и пальцев; **Загрузить позу из JSON…** восстанавливает их.
   Старый `Poses/FireArrow_Default.json` версии 1 содержит только цели;
   новые файлы имеют версию 2 с костями.
9. **Сбросить цели рук** возвращает контролы к последней загруженной позе. Для полного
   возврата к штатной основе снова нажмите **Поза лука из игры**. Действия
   можно отменять через Undo.

Голубая цель — левая кисть, оранжевая — правая, зелёные — локти, красная — прицел.
Оранжевая линия показывает ось стрелы. Кисть перестаёт точно достигать цели,
если цель дальше длины руки: появится предупреждение в Inspector манекена.

Для прямого редактирования костей раскройте `Player Mannequin → Armature → Hips`
и отключите **Предпросмотр (IK)** в окне Pose Lab (то же поле **Preview Enabled**
в Inspector компонента `MagicPlus Pose Lab`). Тогда автоматический
предпросмотр перестанет восстанавливать исходные кости. Включение предпросмотра
снова применяет сохранённую основу и цели рук. Сначала зафиксируйте свои правки
кнопкой **Запомнить правки верха тела**. Имена и длину костей сохраняйте.

Это стенд для позы и процедурного наведения. В скелете есть по три кости
каждого пальца обеих рук. При работе ползунков сохраняются только повороты
выбранного пальца, а остальные кости защищены от пересчёта Humanoid.
У модели мало вершин, поэтому контур кулака и сгибы будут угловатыми.
Позу в игре подключаем отдельным изменением мода после её выбора.

## Прицел и взгляд

В окне есть ряд **Проверенные позы → Start / Loaded / Release**. Он переключает
три согласованных варианта из `Poses/Reviewed`, работает на любой вкладке.
Для просмотра подготовлена сцена `Scenes/MagicPlus_ThreePoseReview.unity`.
В каждом варианте прицел направлен вдоль двух вытянутых пальцев левой руки,
лицо смотрит туда же. Положение рук, разворот корпуса, ноги, длины костей
и жест пальцев сохранены. Loaded и Release используют одинаковое направление;
Start сохраняет авторский подготовительный разворот. Исходные JSON не заменены.
Текущий Start уточнён по ручной расстановке пользователя: левое плечо ближе
к линии левой ноги, грудь и правое плечо немного поданы к цели, два пальца
правой руки начинают движение у тыльной стороны левого запястья. Для дальнейшей
анимации используйте текущий `FireArrow_Start_Reviewed.json`; старый
`FireArrowPoseStart.json` содержит предыдущий вариант с большим разворотом.

После ручного поворота торса направление двух пальцев может расходиться с
прицелом, а голова наследует поворот корпуса. Откройте вкладку **Взгляд**:

- **Прицел по двум пальцам** переносит прицел на направление указательного
  и среднего пальцев левой руки. Видимая поза сохраняется: цели рук и основа
  заново согласуются с повернувшимся Aim Frame. Текущее видимое положение
  правой кисти фиксируется как самостоятельная поза (Натяжение становится 1).
- **Направить голову по прицелу** выравнивает лицо вдоль прицела. Поворот
  распределяется между шеей и головой; руки, корпус и ноги остаются на месте.
  Это разовая настройка позы, не автоматическое слежение головы каждый кадр.
- **Выбрать голову / шею** отключает IK и выбирает кость для вращения через E.
  После ручной правки нажмите **Запомнить правки верха тела**.
- **Точный поворот головы и шеи** позволяет вводить локальные углы с работающим
  IK; эти изменения сразу попадают в сохранённую основу.

При включённых Show Guides видны красная линия прицела, голубая линия пальцев
и фиолетовая линия взгляда. Окно показывает углы расхождения. Ось лица получена
из исходного скелета Avatar: локальная +Z кости Head в этой модели смотрит вбок.
Сохраните исправленный вариант в JSON через вкладку **Поза и руки**.

Если требуется изменить направление всей позы, двигайте прицел при включённом
IK. При построении общей анимации отдельные авторские позы потребуется привести
к одной оси наведения; перенос прицела сам по себе не разворачивает руки.

Вариант `Poses/FireArrow_TwoFingerHold.json` сохраняет штатные ноги и постановку
рук от лука. Левая кисть развёрнута, её поворот частично распределён по
предплечью, пальцы настроены по референсам. Это начальная поза удержания;
анимация подготовки и выпуска ещё не создана.

## Устройство сцены

- Настоящий `player_male` из установленной Valheim: 1010 вершин, 53 skin bones,
  валидный Humanoid Avatar. В манекене оставлены Transform, Animator и
  SkinnedMeshRenderer; материал заменён редакторским URP/Lit.
- `MagicPoseLab` выполняет аналитический IK двух костей с целями кистей
  и направлениями локтей. Длины костей сохраняются. Предпросмотр работает
  в Edit Mode; дополнительный пакет Animation Rigging не нужен.
- Цели находятся в Aim Frame. Наклон ограничивается Pitch Limit и Yaw Limit,
  Body Aim Weight задаёт участие груди. Настройки доступны через
  **Выбрать настройки манекена**.
- Оригинальная основа — снимок результата настоящего `Player_animator`
  после выхода в `Bow Aim Idle 01`: onGround=true, bow_aim=true, statei/statef=3,
  drawpercent=1. Снимок — `LocalReference/NativeBowHold.json`; он работает
  без загруженных игровых пакетов. Это один кадр стойки, а не полный клип.
- Прямое создание `.anim` из runtime-клипов не сохраняет редакторские кривые;
  пустые копии удалены. Для редактируемых клипов требуется отдельное запекание.
- В стенде нижняя часть тела берётся из исходного снимка; правки захватываются
  от Spine и выше. При будущей интеграции в игру ноги должны продолжать
  штатную анимацию стойки/ходьбы/прыжков, а наши движения накладываться на
  верх тела. Снимок ног из стенда не предназначен для замораживания ног в игре.
- `LocalReference` содержит локальную копию игровых меша, Avatar и префаба;
  каталог исключён из Git. Рабочая сцена зависит от этих локальных файлов.
- Предыдущая несохранённая сцена сохранена как `Scenes/BeforeAnimationLab.unity`.

Архив `AssetRipper_export_20261108_152505.zip` содержал встроенные ресурсы Unity
и код: 13 GLB без skins/animations. Манекен получен непосредственно из
`valheim_Data/StreamingAssets/SoftRef/Bundles` установленной игры. DLL и исходники
из архива в Unity-проект не импортировались.

Проверено на Unity 6000.0.75f1: компиляция без предупреждений/ошибок,
реальная деформация меша при перемещении кисти на 6 см, сохранение длин костей,
наведение вверх/вниз, сохранение/открытие сцены, JSON, работа после выгрузки
всех девяти исходных игровых AssetBundle. Дополнительно проверены загрузка
оригинальной основы, сохранение пальцев/груди в JSON v2 и неизменность таза/ног
при правке верха. Для новых контролов проверены реальная деформация пальца,
неизменность остальных костей, сохранение JSON и направление пальцев при
наведении вверх/в сторону. Мод и игровые сохранения не менялись.
