# Полный скелет персонажа Valheim

Откройте `Scenes/MagicPlus_FullSkeleton.unity`, затем меню
**MagicPlus → Full Skeleton Pose**. Play не требуется.

- Выберите кость в списке окна или в Hierarchy:
  `Full Skeleton Pose Lab → Player Mannequin → Armature → Hips`.
- **E** — вращение, **W** — перемещение. Ориентация инструмента **Local**
  использует оси выбранной кости. В окне доступны точные числовые значения.
- Доступны все 56 Transform модели, включая 53 кости меша, таз, ноги,
  стопы, челюсть и все суставы пальцев. Автоматическая анимация отключена.
- **Сбросить весь скелет в T-позу** восстанавливает исходную позу.
  Есть отдельный сброс выбранной кости. Действия поддерживают Ctrl+Z.
- **Сохранить JSON…** записывает фактические локальные положения, повороты
  и масштабы всех объектов скелета; ноги и таз тоже сохраняются.
- **Загрузить JSON…** восстанавливает полный файл. Неподходящий или
  повреждённый JSON отклоняется до изменения позы.
- **Ctrl+S** сохраняет сцену. Для собственных сцен используйте **File → Save As**.

## Поза дыхания

Кнопка **Загрузить FireBreath_Hold_v1** загружает отдельно преобразованную
копию пользовательской позы из `Poses/FireBreath_Hold_v1_FullSkeleton.json`.
Исходный `FireBreath_Hold_v1.json` старого стенда не заменён. Новый JSON
имеет формат `magicplus.full-skeleton`, version 1; прежний формат MagicPoseLab
содержит дополнительные IK-цели и напрямую в этом окне не используется.

Полная поза позволяет экспериментировать с ногами и смещениями суставов.
Для игровой анимации позже отдельно выбирается, какие кости воспроизводить:
например, верх тела — из авторской позы, ноги — из игровой ходьбы.

## Файлы

Сцена, скрипты и необходимые ресурсы манекена лежат внутри `FullSkeletonLab`.
Каталог `Reference` содержит локальные копии меша и Avatar из установленной игры,
исключён из Git и включён в локальный пакет для переноса.
Проект использует уже установленный URP. Дополнительные пакеты не требуются.
Переносимый пакет: `UnityMagicPlus/MagicPlus_FullSkeletonLab.unitypackage`.
